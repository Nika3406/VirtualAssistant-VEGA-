# VEGA 
A virtual assistant that does a list of commands:
1. Basic / Advanced Math Operations
2. Converter Operations (Speed, Length, Currency)
3. Array Operations (Addition, Subtraction, Multiplication, Division)
4. Matrix Operations (Addition, Subtraction, Multiplication)
5. Dataset Predictor using Linear Regression
6. 3 Games (Politics Trivia, Mastermind, Tic Tac Toe)
7. Health Assistant (Terry) that asks questions to determine the patients scale of suicide
8. Vocab Quiz
9. A Text Game (Golden Taco)
10. FPS Simulator using ascii symbols
